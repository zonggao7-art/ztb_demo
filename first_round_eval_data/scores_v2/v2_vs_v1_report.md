# 提示词优化实验报告：v2 vs v1 基线（五模型全量对比）

> 实验日期：2026-08-19 ~ 2026-08-20
> 报告生成：2026-08-20

## 1. 实验目的

验证 v2 结构化法律提示词（角色强化 / 结构化输出约束 / CoT 思维链 / 反幻觉机制）相对 v1 基线提示词的增益，覆盖 3 个大模型与 2 个小模型，为最终选型提供数据依据。

## 2. 变量控制

| 变量 | v1 基线 | v2 实验 | 是否一致 |
|---|---|---|---|
| 测试集（大模型） | testset_1000.jsonl | 同一文件 | ✅ |

| 唯一变量 | v1 提示词模板 | v2 提示词模板 | — |

**对齐方法**：为消除两轮题目覆盖差异（约 0.3%~3.5% 缺口），本报告所有 v1/v2 对比均值均按**题目交集**重新计算（大模型 ~998 题交集，小模型 181/192 题交集），而非直接引用两次 run 的全量均值。

**产物隔离**：v1 基线产物在 `DATA/eval_data/scores/`（原样保留），v2 产物在 `DATA/eval_data/scores_v2/`，互不覆盖。

## 5. 综合结论

1. **反幻觉机制全员生效**：faithfulness 五个模型全部提升（+4.1% ~ +58.0%），且 v1 忠实度越低的模型提升越大（glm 0.39→0.62、minimax 0.60→0.70），说明 v2 的"仅依据给定资料作答"约束对易幻觉模型的矫正作用最强。
2. **正确性 4/5 模型提升**（+1.2% ~ +11.6%），唯一下滑为 qwen（-0.8%，幅度可忽略）。
3. **答案长度统一压缩 42%~68%**：v2 的结构化输出约束显著抑制冗长表述，直接降低推理成本与延迟。
4. **代价一：relevancy 微降**（-0.4% ~ -4.6%）：答案更保守精炼的副作用，属可接受范围。
5. **代价二：小模型思考 token 增加**（qwen +53%、glm +116%）：v2 的 CoT 指令放大推理链长度；qwen3.5-9B 在个别题目上触发 25 万 token 级病态思考链（单题 43~98 分钟），生产环境需配合 max_tokens 上限或思考预算约束。

## 6. 建议

- **提示词采用 v2**：质量增益确定、方向一致，尤其 faithfulness（招投标法律场景的核心指标）全员显著提升。
- **生产部署注意**：为小模型设置合理 max_tokens / 思考预算，防止病态思考链；qwen3.5-9B 若用于生产，建议开启思考预算限制或降级到 v1 提示词 + 后处理截断。
- **选型参考**：大模型中 deepseek_v4_flash 综合最优（三项指标均衡领先）；小模型中 qwen3.5_9b 质量最优但稳定性代价高，glm_z1_9b 在 v2 下改善最大但绝对分仍落后。
