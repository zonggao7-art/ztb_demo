### 3.3 动态阈值标定建议（Q6 交付物）

分布呈**双峰清晰分离**：领域 query 最低 0.931、无关 query 最高 0.053，中间带（0.7~0.9）无样本。判定：

- **0.40 / 0.45 / 0.50 三级初值合理，无需调整**。0.45 中档在当前数据下是空档安全带：未来若出现 top1 0.7~0.9 的边界 query，0.45 档会过滤弱相关候选，行为合理；
- 领域 query 最低分 0.931 距 0.40 阈值余量充足；拒答线由 0.50 档承担，无关 query（<0.06）稳定触发；
- 建议将本分布记录为新基线；后续新增书籍/更换 Reranker 模型时重跑 T9 复核（.env 换模型 SOP 已有约定）。
