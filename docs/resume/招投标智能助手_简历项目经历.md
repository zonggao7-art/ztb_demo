# 招投标智能助手｜Agent 应用开发

**个人独立开发｜项目周期：2 个月｜支持网页与飞书体验**

**技术栈：** Python、LangChain / LangGraph、Milvus、MySQL、BGE-M3、FastAPI / SSE、React / TypeScript。

面向招投标法规检索与企业、中标信息查询，独立完成数据治理、Agent 编排、效果评测及双端接入，构建可交互体验的领域智能助手。

- **Agent 编排与执行治理：** 实现统一主 Agent，封装 6 类只读工具，支持根据中间结果串行调用；通过参数来源绑定、结果范围校验、调用预算与超时控制约束执行，基于证据发布业务结果。
- **RAG 检索优化：** 构建 BGE-M3 + BM25 混合检索、RRF 融合与 Reranker 精排，建立片段级引用溯源；在固定 200 题离线对照评测中，标准证据片段宏平均召回率由 **68.00% 提升至 94.25%**。
- **评测与问题定位：** 构建覆盖 6 类工具的 **280 题 × 3 轮** Agent 评测及故障注入，分层检查动作、参数、证据与结束状态，定位额外调用、依赖歧义和失败处置问题。
- **服务与产品交付：** 基于 FastAPI SSE 统一后端，接入 React 网页与飞书机器人；网页支持进度、引用、取消与断流处理，飞书实现重复事件去重及回复失败时答案复用，完成真实链路联调。
