## 正式运行时的文件

每次运行保存在 `second_round_eval_data/runs/<运行编号>/`：

- `manifest.json`：阶段、题集校验值、知识库、模型名称和检索参数；
- `results.jsonl`：200题回答、最终资料、耗时、状态和系统Token；
- `scores.jsonl`：每题四项Ragas结果或失败原因；
- `scoring_usage.json`：裁判和评分嵌入Token；
- `summary.json`：六项汇总、有效数量和异常数量；
- `report.md`：供人工审核的简明报告。
